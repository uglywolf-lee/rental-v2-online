========================================================
 부동산 관리시스템 - 윈도우 패키징(EXE) 설치 · 빌드 안내
========================================================

[이 문서는 무엇인가요?]
이 프로그램을 윈도우에서 "더블클릭으로 실행되는 EXE"로 만들어
USB에 담아 나눠주기 위한 안내입니다.
- EXE 만들기(빌드)는 파이썬이 설치된 윈도우 PC에서 딱 한 번만 하면 됩니다.
- 완성된 EXE를 받는 사용자(어르신) PC에는 파이썬 설치가 필요 없습니다.


--------------------------------------------------------
 A. EXE 만들기 (제작자 PC에서 1회)
--------------------------------------------------------

1) 준비물
   - 윈도우 PC (10 또는 11)
   - 파이썬 3 설치 (https://www.python.org/downloads/ 또는 Microsoft Store 'Python')
     * 최근 버전은 "Python Install Manager"로 설치됩니다.
       예전의 "Add to PATH" 체크나 Scripts 폴더가 안 보여도 정상입니다.
     * 설치 후 "새" 터미널(cmd)을 열고   py --version   을 입력해
       버전(예: Python 3.14.x)이 나오면 준비 끝입니다.
     * ★ 핵심: python 대신 py 를 쓰면 PATH 설정 없이 바로 됩니다.
       (build_windows.bat 도 py 를 자동으로 사용합니다)

2) 이 프로그램 폴더(rental-v2-online) 전체를 윈도우 PC로 복사합니다.

3) 그 폴더 안의  build_windows.bat  파일을 더블클릭합니다.
   - PyInstaller 설치 -> EXE 빌드 -> 필요한 파일 복사까지 자동 진행됩니다.
   - 처음 한 번은 인터넷 연결이 필요합니다(PyInstaller 내려받기).
   - 검은 창에 "완료!" 가 뜨면 성공입니다.

4) 결과물
   - dist\부동산관리시스템\  폴더가 새로 생깁니다.
   - 이 폴더 전체가 "완성된 프로그램" 입니다.


--------------------------------------------------------
 B. USB 배포 & 실행 (사용자 PC)
--------------------------------------------------------

1) dist\부동산관리시스템  폴더를 통째로 USB에 복사합니다.

2) ★ 최초 1회만: 그 폴더의  install_service.bat  을
   "우클릭 → 관리자 권한으로 실행" 하세요.
   - 방화벽 허용(다른 PC에서 접속 가능) + 부팅 시 자동 실행이 한 번에 등록됩니다.
   - 이 과정을 하면 "네트워크 액세스 허용" 경고창 때문에 접속이 안 되던 문제가 사라집니다.

3) 사용자 PC에서 USB의 그 폴더를 열고
   "RealEstate.exe" 를 더블클릭합니다. (이후에는 부팅 시 자동 실행)

3) 검은 창이 잠깐 뜨고, 잠시 후 브라우저에 로그인 화면이 자동으로 열립니다.
   - 자동으로 안 열리면 브라우저 주소창에   http://localhost:8899   을 입력하세요.

4) 종료: 검은 창을 닫으면 프로그램이 꺼집니다.

5) 로그인 (최초 관리자)
   - 사번: EMP-001
   - 비밀번호: admin123
   * 실제 사용 전 비밀번호를 꼭 바꾸세요.


--------------------------------------------------------
 C. 알아두면 좋은 점
--------------------------------------------------------

- 데이터 저장 위치
  EXE와 같은 폴더의  building_manager.db  파일에 저장됩니다.
  USB에서 실행하면 데이터도 그 USB에 남습니다.

- 자동 백업
  프로그램을 켜거나 데이터가 바뀌면, 같은 폴더의
  _backups\auto\  안에 백업본이 자동으로 쌓입니다(최근 30개 유지).

- 처음부터 빈 상태로 배포하려면
  배포 전에 building_manager.db 파일을 삭제하세요.
  프로그램이 처음 실행될 때 새 데이터베이스를 자동으로 만들고,
  최초 관리자 계정(EMP-001 / admin123)이 생성됩니다.

- OCR(계약서 자동인식) 기능
  EXE에는 포함되지 않습니다. 이 기능은 별도 프로그램(Tesseract) 설치가
  필요하며, 없어도 나머지 기능은 모두 정상 동작합니다.

- 윈도우 첫 실행 경고
  "Windows Defender / SmartScreen" 경고가 뜰 수 있습니다.
  서명되지 않은 프로그램이라 그렇습니다.
  "추가 정보" -> "실행" 을 눌러 진행하면 됩니다.


--------------------------------------------------------
 D. 문제가 생기면
--------------------------------------------------------

- "python을(를) 찾을 수 없습니다"
  -> 파이썬 설치 시 "Add Python to PATH" 체크를 놓친 것입니다. 재설치하며 체크.

- 브라우저가 안 열림
  -> 주소창에  http://localhost:8899  을 직접 입력.

- 실행했는데 화면이 안 뜸(포트 8899 사용 중)
  -> 다른 프로그램이 8899을 쓰는 경우입니다. 해당 프로그램을 끄고 다시 실행.

- 백신이 EXE를 차단
  -> 백신의 예외(허용) 목록에 등록.

끝.
