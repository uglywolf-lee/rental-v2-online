오렌지파이 서버 — 터미널 명령어 모음
====================================
맥에서 "터미널" 앱을 열고, 아래 줄을 그대로 복사해 붙여넣고 엔터를 치면 됩니다.
(따라 치지 마시고 복사해서 붙여넣으세요. 오타가 안 납니다)

서버 주소: 100.114.91.81
계정: uglywolf


■ 1. 서버에 들어가기
--------------------
ssh uglywolf@100.114.91.81

  → 들어가면 맨 앞 글자가 uglywolf@rental 로 바뀝니다. 여기가 오렌지파이 안입니다.
  → 나올 때는  exit  라고 치면 됩니다.


■ 2. 프로그램이 잘 돌고 있는지 보기
-----------------------------------
ssh uglywolf@100.114.91.81 "systemctl status rental --no-pager"

  → 초록색 active (running) 이 보이면 정상입니다.


■ 3. 프로그램 다시 시작하기
---------------------------
ssh uglywolf@100.114.91.81 "sudo systemctl restart rental"

  → 화면이 이상하거나 멈춘 것 같을 때 씁니다. 데이터는 그대로입니다.


■ 4. 무슨 일이 있었는지 기록 보기
---------------------------------
ssh uglywolf@100.114.91.81 "journalctl -u rental -n 50 --no-pager"

  → 최근 50줄이 나옵니다. 오류를 찾을 때 씁니다.
  → 실시간으로 계속 보려면 -n 50 --no-pager 대신 -f 를 쓰고, 멈출 때 Control+C.


■ 5. 프로그램 화면 열기
-----------------------
브라우저 주소창에 그대로 입력:

http://100.114.91.81:8899

  → 맥, 아이폰, 어디서든 됩니다. Tailscale이 켜져 있기만 하면 됩니다.


■ 6. 최신 코드를 서버에 올리기
------------------------------
ssh uglywolf@100.114.91.81 "cd ~/rental-v2-online && git pull && sudo systemctl restart rental"

  → 맥에서 git push 를 먼저 한 뒤에 실행합니다.
  → DB(입력한 자료)는 건드리지 않습니다.


■ 7. 자료(DB) 백업 잘 되고 있는지 확인
--------------------------------------
집 라즈베리파이가 매일 새벽 3시 30분에 자동으로 가져갑니다.

ssh uglywolf@100.104.174.40 "tail -5 /mnt/USB32G/data/부동산백업/백업기록.txt"

  → 맨 아래 날짜가 오늘이나 어제면 정상입니다.
  → 며칠 전 날짜에서 멈춰 있으면 백업이 안 되고 있는 것입니다.


■ 8. 서버 온도 보기 (여름에 한 번씩)
------------------------------------
ssh uglywolf@100.114.91.81 "cat /sys/class/thermal/thermal_zone0/temp"

  → 나온 숫자에서 뒤 세 자리를 빼면 온도입니다. (예: 58000 → 58도)
  → 70도 아래면 괜찮습니다.

알아두면 좋은 것

* 명령이 안 먹고 멈춰 있으면 Control 키와 C 를 함께 누르세요. 취소됩니다.
* "Permission denied" 가 나오면 sudo 를 앞에 붙여야 하는 명령입니다.
* Tailscale이 꺼져 있으면 아무것도 안 됩니다. 맥 위쪽 메뉴막대에서 확인하세요.
